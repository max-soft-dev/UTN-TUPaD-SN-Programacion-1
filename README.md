# Programación 1 (UTN - A Distancia)
## Introducción a los Trabajos Prácticos (Unidades 3 a 5)

Este documento presenta una guía estructurada de los **Trabajos Prácticos (TPs)** correspondientes al núcleo central de la materia, enfocados en el desarrollo de la lógica algorítmica utilizando el lenguaje de programación **Python**.

## 📌 Unidad 3: Estructuras de Control de Flujo

Esta unidad se enfoca en que los programas dejen de ser secuencias lineales y comiencen a tomar decisiones o a repetir acciones según ciertas condiciones.

### 🔹 Objetivos Generales de los TPs
* Diseñar bloques de código condicionales y ciclos iterativos eficientes.
* Controlar el flujo de datos según variables de entrada.

### 🛠️ Contenidos Prácticos Evaluados
* **Condicionales Simples y Compuestos:** Uso de `if`, `elif` y `else` para bifurcar el camino del programa.
* **Operadores Lógicos y de Comparación:** Construcción de condiciones complejas mediante `and`, `or`, `not`, `<`, `>`, `==`, y `!=`.
* **Ciclos Condicionales (Bucle `while`):** Implementación de iteraciones basadas en el cumplimiento de una condición (ideal para menús de opciones y validaciones).
* **Ciclos Definidos (Bucle `for`):** Recorrido de rangos numéricos mediante la función `range()` y estructuras de datos básicas.

## 📌 Unidad 4: Modularización y Funciones

El propósito de esta unidad es aprender a dividir problemas complejos en subproblemas más pequeños y manejables, promoviendo la reutilización del código.

### 🔹 Objetivos Generales de los TPs
* Descomponer un software en módulos lógicos independientes.
* Evitar la repetición de código innecesario (*DRY - Don't Repeat Yourself*).

### 🛠️ Contenidos Prácticos Evaluados
* **Definición de Funciones:** Sintaxis básica con la palabra reservada `def`.
* **Pasaje de Parámetros:** Configuración de argumentos obligatorios, opcionales y por defecto.
* **Retorno de Valores:** Uso de `return` para enviar datos procesados de vuelta al programa principal.
* **Ámbito de Variables (Scope):** Diferenciación y manejo correcto de variables locales y globales.

## 📌 Unidad 5: Estructuras de Datos Secuenciales

En esta fase se abandona el uso exclusivo de variables simples para empezar a manipular colecciones de datos agrupados bajo un mismo nombre.

### 🔹 Objetivos Generales de los TPs
* Almacenar, ordenar y procesar conjuntos masivos de información en memoria.
* Seleccionar la estructura de datos adecuada para cada problema de negocio.

### 🛠️ Contenidos Prácticos Evaluados
* **Listas (`list`):** Creación, indexación, rebanado (*slicing*), mutabilidad y métodos principales (`append()`, `insert()`, `pop()`, `remove()`).
* **Tuplas (`tuple`):** Uso de colecciones inmutables para proteger datos fijos.
* **Diccionarios (`dict`):** Almacenamiento de datos mediante pares clave-valor y optimización de búsquedas.
* **Métodos de Recorrido:** Integración de bucles `for` y comprensiones de listas (*list comprehensions*) para filtrar y transformar datos.
